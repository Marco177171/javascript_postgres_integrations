Documentation

JPI is a minimal, parametric API and WebApp framework.

It's written in JavaScript, and it leverages these NPM packages by default:

PostgresJS

JPI features a set of standard operations to post and edit content to a Postgres DB.

JsonWebTokens

JPI comes with a preconfigured authentication system that operates through JWT.

Bcrypt

JPI encrypts and validates users' passwords using Bcrypt NPM package
