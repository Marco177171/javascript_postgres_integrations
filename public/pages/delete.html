DELETEing objects from the DB

In order to DELETE objects on a table, call this endpoint:

.../api?table=*table_name* | method DELETE

The DELETE method automatically redirects the request to the Delete() function.

The function Delete() executes the DELETE FROM *table* WHERE ...; query in Postgres.

Only define ?table=... in the URL. All other entries will be ignored.

Examples:
.../api?table=cars
.../api?table=photographers
.../api?table=computers

In order to specify the objects to erase, use the body in the fetch() Request.

Define columns and values. The API will erase the result(s) of the query.

Example: DELETE all users whose name is "Marco".

async function DeleteUser() {
	try {
		const result = await fetch("/api?table=users", {
			method: "DELETE",
			// headers: {
			// 	"Authorization": `Bearer ${localStorage.getItem("token")}`
			// }
			body: JSON.stringify({
				"name": "Marco"
			})
		});
		const result_json = await result.json();
		console.log(result_json);
	} catch (error) {
		console.error(error);
	}
}
