GETting objects using LIKE

In order to find all the objects whose values contain one or more pieces of string, call this endpoint:

.../api/like_search?table=*table_name*&P1=...&P2=... | method GET

The GET method automatically redirects the request to the LikeSearch() function.

The function LikeSearch() executes the SELECT * FROM *table* WHERE P1 LIKE '%value%' AND P2 LIKE "%value%" AND ...; query in Postgres.

If only table is defined in the URL, the DB will return all the entries.

Examples:
.../api/like_search?table=cars&brand=Merc -> Returns all *Merc*edes
.../api/like_search?table=photographers&last_name=on -> Returns both Richard Aved*on* and Henri Cartier-Bress*on*
.../api/like_search?table=computers&brand=App -> Returns all *App*le conputers

Example: GET all users whose name contains "Mar"

async function GetUsers() {
	try {
		const users = await fetch("/api/like_search?table=users&name=Mar", {
			method: "GET",
			// headers: {
			// 	"Authorization": `Bearer ${localStorage.getItem("token")}`
			// }
		});
		const users_json = await users.json();
		console.log(users_json);
	} catch (error) {
		console.error(error);
	}
}
