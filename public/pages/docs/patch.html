PATCHing objects on the DB

In order to edit an existing object with PATCH, call this endpoint:

.../api?table=*table_name* | method PATCH

The PUT method automatically redirects the request to the Patch() function.

The function Patch() executes the UPDATE *table* SET (body) WHERE (query); query in Postgres.

Specify ?table=*...* to set the table. Define a query to find the object to edit.

Examples:
.../api?table=cars&brand=Mercedes | Edit all Mercedes objects
.../api?table=photographers&name=Robert&last_name=Capa | Edit Robert Capa
.../api?table=computers&brand=Apple&model=MacBook&year=2007 | Edit Apple MacBook from 2007

Use the body in the fetch() request in order to specify the contents of the update.

Use JSON.stringify({...}) in order to send the body in the correct format.

Example: Edit an entry with PATCH.

async function EditCar() {
	try {
		const result = await fetch("/api?table=cars&brand=Mercedes&model=Vito", {

			// },
