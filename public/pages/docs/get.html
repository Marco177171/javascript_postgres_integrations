GETting objects from the DB

In order to GET the objects on a table, call this endpoint:

.../api?table=*table_name* | method GET

The GET method automatically redirects the request to the Search() function.

The function Search() executes the SELECT * FROM *table* WHERE *...*; query in Postgres.

If only table is defined in the URL, the DB will return all the entries.

Examples:
.../api?table=cars&brand=Mercedes
.../api?table=photographers&name=Robert&last_name=Capa
.../api?table=computers&brand=Apple&model=MacBook&year=2007

If a query is specified in the URL, the DB will filter the results using the AND operator.

Example: GET all users

async function GetUsers() {
	try {
		const users = await fetch("/api?table=users", {
			method: "GET",
			// headers: {
			// 	"Authorization": `Bearer ${localStorage.getItem("token")}`
			// }
		});
		const users_json = await users.json();
		console.log(users_json);
	} catch (error) {
		console.error(error);
	}
}
