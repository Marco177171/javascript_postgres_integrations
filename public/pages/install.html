Installing JPI

Get JPI from GitHub:

git clone git@github.com:Marco177171/javascript_postgres_integrations.git

Install node_modules:

cd javascript_postgres_integrations
npm i

Copy and edit the .env.example file:

cp .env.example .env

Open the .env file and update it if needed.

If you need a new DB and Adminer, create them:

docker compose up --build

Launch the server:

node --env-file=.env server.js

Or use the script in package.json:

npm start
