POSTing objects to the DB

In order to POST a new object to a table, call this endpoint:

.../api?table=*table_name* | method POST

The POST method automatically redirects the request to the Post() function.

The function Post() executes the INSERT INTO *table* (columns) VALUES (values) ON CONFLICT DO NOTHING; query in Postgres.

Specify ?table=*...* in the Request's URL. All other entries will be ignored.

Define Unique constraints in the DB for the ON CONFLICT DO NOTHING clause to take effect.

Examples:
.../api?table=cars
.../api?table=photographers
.../api?table=computers

Use the body in the fetch() request in order to specify the contents.

Use JSON.stringify({...}) in order to send the body in the correct format.
